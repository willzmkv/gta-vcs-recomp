Fixes and improvements (#90)

- **Windows renderer defaults:** Switched the Windows default renderer to **Direct3D 12**, preventing AMD D3D11 CPU bottlenecks on fresh installs, and fixed the launcher ↔ game renderer selection for **D3D11**, **Vulkan**, and **Direct3D 12** (including the Vulkan badge and renderer resets in **F2 → Graphics**).
- **Automatic button prompts by default:** Button prompts (**F2 → Enhancements → Button prompts**) now default to **Automatic** on fresh installs and switch smoothly between Keyboard & mouse and PlayStation, Xbox, or Nintendo Switch icons on gentle mouse movement (including inside the pause menu), keyboard input, or gamepad sticks and triggers past the deadzone.
- **Game language & PT-BR translation toggle:** Defaulted the bundled **PT-BR (VCS.rec)** translation mod to off until selected, added a **Game Language** switcher under **F2 → Audio & Game**, and synchronized the launcher's first-run modal and sidebar language switcher (**PT-BR** / **ENGLISH**) with the active translation mod without overriding third-party language packs.
- **Pause menu tabs in translations:** Automatically adjusts pause menu tab spacing when translated labels would otherwise overlap (such as *Informações* / *Jogo* or *Información* / *Juego*), yielding automatically when a mod provides custom pause menu layouts.
- **Mod Loader launcher sync & interface mods:** Synchronized the active mod folder between the launcher and the game when using custom build directories, and added support for loose interface (`.psp`) files in the Mod Loader and launcher mod compatibility scanner.
- **Fort Baxter & HD World ground LOD overlap:** Fixed coarse low-detail terrain sectors (such as Fort Baxter's courtyard slabs at `07:00` or when toggling **Detailed city distance**) popping back on top of detailed streets and covering characters' feet, and kept script-switched mission buildings in sync on the same frame.
- **PC mouse camera & Free aim defaults:** Enabled **Free aim** (**F2 → Keyboard → Free aim**) by default on fresh installs, removed the PS2 on-foot camera auto-swing when strafing or walking backwards while keeping 360° free orbit while standing still and camera-aligned steering with `W`, exposed the PC mouse options (**Free aim**, **Invert mouse Y**, **Car camera sensitivity**, **Car camera return**) in **Launcher → Controls → Settings & Keys**, and fixed large mouse flick wrapping on vehicle-mounted weapons.

Updating: on Windows, open the launcher and go to **Settings → Updates → Update now**, or download the standalone launcher / extract `VCS-Recomp-1.0.06-windows.zip` into your game folder. Your saves aren't touched. On Linux, update from Settings in the same way or download the new AppImage.

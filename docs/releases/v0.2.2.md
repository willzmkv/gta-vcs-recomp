**Full Changelog**: https://github.com/gothamor/gta-vcs-recomp/compare/v0.2.1...v0.2.2

New: building works again after updating to 0.2.1

- Windows: building the game stopped at "Setting up the build failed", with "Could NOT find Python3" in the log (#67, #68, #70, #73). This happened on every PC that didn't have its own Python installed, or had a broken one. 0.2.1 needed Python while building, but only looked for one installed on the PC, not the one that comes with the game's folder. It now uses the one in the game's folder. You don't need to install Python, and if you installed it only to get around this, you can uninstall it.

Fixes

- Windows: in a folder with a long path, like the ones Quiver installs into, building could stop right at the start with nothing in the log while the compiler was being unpacked (#69). This should hopefully be fixed now; we couldn't reproduce it here.
- Windows: a disc image whose file name has an unusual character in it (like "꞉" instead of ":") made the build stop with "A tool could not run" (#62).

Launcher

- An update that can't replace a file, because another program like an antivirus is holding it, no longer leaves the folder half old and half new (#66). It now says which file it couldn't replace, keeps the folder on the old version, and you can just update again. This arrives with this version, so it helps from the next update on.

Updating: on Windows, go to Settings → Updates → Update now in the launcher, close the launcher and start it again, then update the build. If your build failed after 0.2.1, this build takes as long as a first build, because 0.2.1 changed the compiler and that build never finished. Otherwise it only rebuilds the shaders and links the game again. Your saves aren't touched. If an earlier update stopped halfway (#66), or the launcher won't update, extract the zip into a new folder instead. On Linux, update from Settings in the same way, or download the new AppImage.

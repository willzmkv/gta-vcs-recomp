**Full Changelog**: https://github.com/gothamor/gta-vcs-recomp/compare/v0.2.0...v0.2.1

New: no Visual Studio needed on Windows

- The game is now built with [llvm-mingw](https://github.com/mstorsjo/llvm-mingw) (clang), which the first build downloads by itself (~190 MB, once). You no longer have to install Visual Studio. It runs as fast as before.
- If you installed Visual Studio only for this game, you can uninstall it.
- The first build after updating compiles the whole game again, once, because the compiler changed.

The car camera

- The mouse now turns the camera behind a car freely. When you stop moving the mouse, the camera eases back behind the car. Before, it moved slowly and fought you.
- New in the game's settings (F2) → Keyboard: **Car camera sensitivity** (how far the mouse turns the camera in a car, separately from on foot) and **Car camera return** (how long the camera waits before it goes back behind the car; 1.5 s by default).
- The gamepad's right stick takes the camera back from the mouse straight away. Before, it did nothing until the camera was back behind the car.

Fixes

- Fire, explosions and flame-thrower flames were invisible on AMD graphics cards (#4). This should hopefully be fixed now.
- Bikes no longer fishtail or spin onto their side when braking at high frame rates (144 fps and up) (#64).
- The frame rate cap "Display refresh" stayed at 60 fps after the game was restarted, until you changed the setting again (#64).
- Farewell To Arms: the helicopter door gun no longer snaps to the left the first time you turn right. With free aim on, the mouse or right stick aims it and the gamepad's R1 fires.
- Linux: on Fedora with RPMFusion's FFmpeg, installing the build's packages failed because of a package conflict, and none of the other packages were installed either (#63).

Launcher

- After an update, a **Restart** button closes the launcher and opens the new one. This arrives with this version, so you'll first see it on the next update.

Updating: on Windows, go to Settings → Updates → Update now in the launcher, close the launcher and start it again, then update the build. This first build after updating takes as long as a first build (see above). Your saves aren't touched. You can also extract the zip into a new folder. On Linux, update from Settings in the same way, or download the new AppImage.
